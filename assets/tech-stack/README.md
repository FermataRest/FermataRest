# Tech stack icons

These icons are stored with the profile so their rendering does not depend on a third-party icon generator deployment.

- The 11 animated `*-icon.svg` files are unchanged copies from [TechStack Generator](https://github.com/qkrdmstlr3/techstack-generator/tree/1a8656741692dfe08effc82600f4d0d4bb87d420/static), commit `1a8656741692dfe08effc82600f4d0d4bb87d420`. Copyright (c) 2021 shellboy; see [MIT license](LICENSE-techstack-generator.txt).
- NumPy, pandas, OpenAI, and Canva use the paths from [Simple Icons 15.0.0](https://github.com/simple-icons/simple-icons/tree/15.0.0/icons), distributed under [CC0](LICENSE-simple-icons.md). LangGraph and LangChain preserve the newer paths served by `https://cdn.simpleicons.org/langgraph/white` and `https://cdn.simpleicons.org/langchain/white`, saved on 2026-11-05 under the same CC0 license. Explicit fills and rounded backing tiles keep these six logos visible in light and dark themes.

Brand names and logos remain the property of their respective owners.
